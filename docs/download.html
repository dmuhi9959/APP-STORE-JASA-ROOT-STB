Cara pasang di STB

  1. Buka halaman ini dari browser STB (alamat yang sama dengan katalog), lalu tekan tombol unduh.
  2. Kalau browser STB tidak bisa mengunduh, salin APK lewat flashdisk atau kirim via adb install AAP-STORE.apk.
  3. Saat muncul peringatan keamanan, pilih Setelan → aktifkan Izinkan dari sumber ini.
  4. Tekan Instal, lalu buka AAP STORE dari launcher TV.
  5. Kalau katalog tidak muncul, tekan tombol Sumber dan isi alamat catalog.json.
