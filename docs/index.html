⬇ Unduh & Instal

Setelah terunduh, buka notifikasi / aplikasi Files di STB lalu tekan APK-nya untuk instal. Izinkan “Instal aplikasi tidak dikenal” sekali saja.

Cara instal di STB / Android TV

  1. Buka AAP STORE di browser STB (Chrome / TV Bro / Puffin). Ketik alamat situsnya, atau kirim link-nya ke TV.
  2. Pilih aplikasi lalu tekan Unduh & Instal. APK akan masuk ke folder Download.
  3. Izinkan instalasi: saat muncul peringatan, pilih Setelan → aktifkan Izinkan dari sumber ini untuk browser yang dipakai.
  4. Instal: buka notifikasi unduhan atau aplikasi Files / File Manager, tekan file APK, pilih Instal.
  5. Selesai. Aplikasi muncul di launcher STB. Ulangi untuk aplikasi lain.

Tips

  • Kalau tombol unduh tidak merespons, salin link APK lalu tempel di browser STB.
  • Aktifkan Instal dari sumber tidak dikenal per-aplikasi (browser), bukan global, agar lebih aman.
  • Tekan Esc / tombol Back untuk menutup jendela ini.
